# Motion candidate studies

This folder contains 18 deterministic motion studies for the next Ganesha 108 production sprint. Each candidate has twelve 768px WebP frames and a looping WebP preview at 24 fps (0.5 seconds).

Open `index.html` in a local preview to compare the loops. The original 108 artwork assets under `src/assets/artworks/` are unchanged.

These are shortlist studies, not final delivery exports. After selecting nine, encode the selected frame sets as muted WebM with MP4 fallback and retain the source still as a poster.
